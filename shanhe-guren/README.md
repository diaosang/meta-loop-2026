# 山河故人 0.3｜诸国征伐与乱世生存

中式古风聚落经营与国家征伐原型。核心循环从单纯求生升级为：**发展聚落 → 储备粮草 → 招募训练 → 抵御入侵 → 讨伐诸国 → 统一天下**。

## 运行方式

直接在浏览器打开 `index.html` 即可，无需安装依赖或启动服务器。进度自动保存在当前浏览器的 `localStorage` 中。0.2 旧存档会在首次载入时自动迁移。

## 0.3 核心系统

### 外部威胁优先

- 第 7 日起，外敌按随机间隔（约 8–13 日）来犯。
- 入侵强度会随统一进度与威胁值提高。
- 面对来袭可选择守城迎战、献粮议和或收缩外围。
- 守城战力由兵力、军心、操练、巡防人员、木栅和望楼共同决定。
- 战败会损失兵员、粮草与材料，并可能损毁田地、造成居民战伤。

### 天灾与随机事件

- 天灾约每 10–16 日出现一次，包含旱情、蝗灾、洪水。
- 可投入木料、石料等资源进行预防；不处理会损毁田地或压低后续收成。
- 原有流民、商旅、疾病、山匪、乡绅等事件仍会出现。

### 军事与统一天下

- 初始拥有一支残余乡勇队伍。
- 可以花费粮食与银钱招募乡勇；军队规模受军营数量限制。
- 居民可被安排为“操练兵卒”，提高军队训练度与军心。
- 建造军营可提升募兵容量；木栅、望楼提高守城能力。
- 诸国依次包括北燕、东越、西楚、秦川，各自拥有不同守军与城防。
- 出征消耗粮草和银钱；战斗根据双方战力结算，失败会造成伤亡。
- **胜利条件：攻取全部四国，达成山河一统。**胜利后仍可继续经营。

### 有上限的资源经济

| 资源 | 基础上限 | 仓廪每座增加 |
|---|---:|---:|
| 粮食 | 70 | +45 |
| 木料 | 60 | +18 |
| 石料 | 50 | +18 |
| 银钱 | 60 | +15 |
| 药材 | 24 | +10 |
| 乡望 | 100 | 不增加 |

超过上限的生产或奖励不会继续入库。仓廪可提高多类资源容量。

### 居民与聚落

- 地图：10×7 地形格，包含草地、林地、石坡、溪流和旧屋遗址。
- 居民拥有技能、性格、心情、饥饿、疲劳、健康、目标与记忆。
- 工作包括耕作、采集、伐木、采石、营造、巡逻、医护、操练和休息。
- 建筑包含草庐、田地、水井、工棚、药圃、木栅、仓廪、望楼和军营。
- 工程需要居民实际投入施工，不会瞬间建成。
- 四季、天气、疾病和人物关系继续影响聚落运营。

## 操作建议

1. 初期安排居民生产粮食、木料和石料，优先建造木栅、望楼与田地。
2. 用银钱和粮食招募乡勇；建成军营后可扩大兵力上限。
3. 安排居民操练，提高军队训练度；保留足够粮草应对围攻。
4. 天灾出现时权衡投入成本，避免田地损毁与长期减产。
5. 观察四国守备，择机出征；每次远征前预留伤亡和补给成本。

## 版本边界

0.3 是单机玩法验证原型。已实现入侵事件、守城结算、军队招募与操练、四国征伐、胜利条件、天灾事件、资源硬上限和 0.2 存档迁移。尚未实现自由寻路、战场动画、完整外交、科技树、多地图与跨设备云存档。
