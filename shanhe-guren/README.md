# 山河故人 0.2

中式古风聚落生存与故事模拟原型，借鉴《环世界》的殖民地管理与涌现式叙事思路。

## 运行

直接在浏览器打开 `index.html` 即可，无需安装依赖或启动服务器。游戏进度自动保存在当前浏览器的 localStorage 中。

## 当前系统

- 10×7 地形地图：草地、林地、石坡、溪流、旧屋遗址
- 居民属性：技能、性格、心情、饥饿、疲劳、健康、个人目标与记忆
- 工作安排：耕作、采集、伐木、采石、营造、巡逻、医护、休息
- 自主行为：严重饥饿时优先找食物、过劳时休息、低落时主动社交
- 聚落营造：草庐、田地、水井、工棚、药圃、木栅、粮仓、望楼；工程需要施工进度
- 季节与天气：季节收成、寒潮影响、疾病风险
- 随机事件：流民、商旅、山匪、疾病、地窖、乡绅征粮等
- 人际关系：好感变化、争执、记忆片段
- 存档：自动存档、手动存档、读取和重开

## 操作

1. 在左侧居民卡片中选择每个人的当日差事。
2. 选择营造项目，再点击地图上的草地或旧屋遗址放置工程。
3. 安排居民从事“营造”以推进工程；工程完成后才会产生建筑效果。
4. 每日推进前处理突发事件；注意粮食、疲劳和疾病。
