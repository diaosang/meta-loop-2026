# 凤阙长歌 · 宫城漫游 V33

这次将人物放进一张可以实际走动的宫城地图。入口在「宫门」页面顶部，也可以直接点「宫苑」。

## 怎么玩

- **点空地**：女帝沿路走过去；建筑、池水、树干和长凳会挡路。
- **点人物**：女帝走近他，再点「交谈」，接着玩原来的人物互动。
- **点建筑名**：走到门前，进入上朝、人物、初荐或疆域功能。

NPC 会在宫城各处走动，到地方歇一会儿再继续。许知衡、姜禹瀛、谢无咎、叶锦、叶桢、宋玉衡和陆景明各有不同的去处；已经离京、出征、任地方官或不在人世的人，不会被强行放回宫里。

方向键 / WASD 也能走。地图右下方有四个方向按钮；上方可以暂停、缩放、回到女帝和全屏。拖动地图可以查看别处。

**走路与看地图免费，不推动日期，也不扣行动、国库或粮食。** 真正开始原有会面、国事时，仍按原游戏的规则计算。

## 保留的内容

原始设定、开篇、对白与新手引导文字保持原样。疆域图仍负责收地、调兵与地方经营；宫城图负责人物在场景里的走动与见面，不把战略地图替换为装饰图。

位置随原有存档保存。打开带 `scene=palace` 参数的试玩链接时，已有进度会直接显示宫城，不另开新局。

## 实现与验证

- 使用内置于 HTML 的 Three.js r160 和程序化低模网格，建筑、人物、灯光、阴影均由 WebGL 实时绘制；不是 CSS 背景透视。
- 逻辑位于 `源代码/simulation/city-walk-v33.js`；场景与接口位于 `源代码/demo-city-v33.js`；样式位于 `源代码/city-v33.css`。
- 路径使用带道路权重的网格寻路。NPC 的路线和停留是规则驱动的场景行为，不会伪造办事结果或向朝廷账目写入奖励。
- 渲染器在页面切换时复用；关闭页面、出现对话窗、切到其他页时停止推进场景走动。静态建筑按材质合并，屏幕像素比上限 1.5，目标更新频率约 30 帧。
- 已验证：各入口互相可达、绕池与建筑避障、不同帧率移动距离一致、非法旧位置修复；以及实际浏览器中的点击行走、NPC 自行移动、暂停、键盘移动、走近交谈、走到殿前上朝、页面切换、位置读档和 390 像素视口。
- 性能数据只代表测试环境，未宣称在所有手机上都达到固定帧率。人物为低模小人，后续可单独替换模型、衣装与动画。

## 打开与构建

离线直接打开 `index.html` 即可，无需下载外部脚本。浏览器须支持 WebGL；若地图无法启动，页面会显示原因和重试按钮，原有玩法仍保留。

重新构建：`python 源代码/build_web_demo.py`。构建脚本沿用随包的 `网页Demo/index.html` 基础样式和原始配表。

逻辑测试：`node 源代码/tests/city-walk-v33.test.cjs`。

Three.js 的 MIT 许可证保存在 `源代码/vendor/THREE-LICENSE.txt`。
