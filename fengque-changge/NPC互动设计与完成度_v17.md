# V17 · 与卿相识

本轮以最后提供的八项互动文档为准，继续在已有网页版整合包上修改。保留V16.1简化上朝、V16家族宫室与存档，Godot迁移继续暂缓。

## 最终菜单

点击人物立绘或「查看人物」，先看公开身份、真实年龄、性情、家族和当日状况，再进入八项：

| 主项 | 已接入的行为 |
| --- | --- |
| 闲谈 | 近日忙什么、平日兴致、实际天气时节、茶点小事与接话 |
| 关心 | 起居身体、实际压力、亲属近况、家计；有具体不快时才可道歉 |
| 赏赐 | 合用小物、按实绩赏银、相知之后的信物；先问偏好 |
| 邀约 | 饮茶、游园、下棋与明日之约；忙碌时婉拒，日后有概率主动续约 |
| 试探 | 对女帝的态度、实际旧交、家世、已经听过的旧事；可能保留、护旧交或反问 |
| 议事 | 眼前真实奏事的立场、本人擅长的学问；建议不等于已下旨 |
| 委派 | 指定本人处理已有地方差事；谢无咎沿原查证系统办旧案 |
| 人物经历 | 公开资料、目标、家谱、原有交际、共同记忆、主动请见及前代留档 |

任用、查证、荐举、谢恩、说心里话、入宫和亲密安排收在「依身份开放的专属操作」。不会给普通百姓显示任命六部、调兵或审问的假按钮。许知衡仍不入后宫，姜禹瀛仍有姜氏立场，谢无咎的秘密仍须本人亲口说明。

## 时间与余力

资料、家谱和经历可以免费查看。开始一场会面用1次安排，会面内可说3回话；闲谈、关心等不再每点一次都扣全天安排。具体差事、任命和另行赴约仍按真实命令扣费。

上朝时不能同时陪人游园；忙碌、不在随行名册、已经离世、尚未成年、已有配偶或属前代亲缘关系，都继续按原边界判断。忙碌人物可收到一句邀约，但回应可能是婉拒，不能因此扣好感。

## 赏赐合并入口，账目与意义仍分清

按最后文档，「赠礼」不再是与赏赐并列的一级菜单。小物与信物从宫里支钱；论功赏银从朝廷账中支出，并要求确有未论赏的已完成差事。一次公家赏银不会自动增加私人亲近。

小物每月一次，论赏按真实差事编号去重，信物本代一次。许知衡在官兵欠饷未清时会辞去额外金银，银仍留库中；谢无咎不使用普通花钱刷好感菜单。未凭空生成「祖父遗物」之类特殊道具。

## 互动有具体记忆

重要相处记录时间、参与人、本代君主、行为、态度、原因、原回复、钱粮与关系变化、情绪变化、标签及后续来源编号。近况和闲谈复用原去重机制，实际说出口才写记忆；反复预览不刷奖励。

熟悉、信任、亲近沿用真实相处与原关系；敬重、戒备单独续记，忠诚保持独立。身体欠安时的关心不凭一句话治病或必加好感。试探得到的说法先记未核，不会变成查实罪证。

随机人物的家世读取实际家族、父亲和目标，亲属依稳定ID引用。隐情依原亲疏与线索分段解锁。前代的私情不转给新君，前代相处仍可从人物经历展开；亡者留档后仍能查历代记忆。

## NPC主动来往

新接入三类有依据的请见：前回因忙婉拒后的续约、婚育或长辈离世导致家计紧张后的求助、对实际政治决定有负面反应后的再陈主张。续约和家事有真实亲疏门槛及概率，达到门槛也不是每日必来。援助实际增加该户家产，不混入朝廷支出。

小笺和家事归记事，可从人物经历查看。御前要事继续按原呈报系统，人物日常不抢占朝堂消息。NPC之间的结交、争执、婚育等沿用原世界模拟，并非只围着女帝更新。

本版新增人物逻辑检查30项、真实断网浏览器操作检查15项，原经营、人物旧案、前朝、恢复批阅、日常去重、家族宫室和传位规则回归186项。浏览器覆盖320、390及1280像素；真实逐日推进验证NPC补约。存档沿用完整格式，并新增互动归属与引用校验。
