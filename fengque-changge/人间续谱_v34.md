# 凤阙长歌 V34 · 人间续谱

宫城走动场景已从当前游戏撤下，恢复简洁界面。新玩法从首页「逛京城」或顶栏「京城」进入。

## 京城生活

新增12位人物，男女各6位：柳见春、闻砚秋、秦织月、顾青蘅、霍照野、裴听澜、沈照棠、陆闻舟、温知夏、江怀序、阮清辞、钟望舒。他们有自己的身份、背景、年龄、所学、家族和婚姻记录，可以通过原有人物互动继续相识。

六家店：云来茶肆、听雨书铺、绮罗衣坊、回春医馆、百炼铁铺、归云客栈。进店查看免费；买小物、坐坐闲谈、帮忙备货、送礼、入股、添置店面分别结算。

小物放进随身物品；不同店铺需要彼此的货物。备货可以赚一点私钱、加深交情。闲谈提升本店对应所学。入股后每月分红，最多添置到三级；店面与股份保存在世界存档里，传位后继续承接。掌柜去世且有成年子女时，由后人接手；没有可接手的成年子女时暂歇，不凭空复活掌柜。

店铺使用内帑，不直接扣国库。同店闲谈、备货与送礼每天各一次。查看和买小物不耗安排，其余操作按按钮消耗安排；不要把所有日常都花在同一种事上。

## 赐婚与自行成家

「赐婚与姻缘」可选两位成年、未婚、非近亲的人拟旨赐婚。已入内廷、有旧配偶、核心固定人物等不会被强行纳入随机配对。赐婚会得到领旨或婉拒结果；婉拒后不重复逼婚，结果不会通过重复点按重抽。

适婚NPC同地往来时，会随月份积累亲近，经过相识、互有情意，再自行成婚。婚后每月有机会记家中有喜，九个月后添丁；同性与异性家庭都适用。双方都须成年，较年轻一方不超过45岁、另一方不超过55岁，每户最多三个孩子。

这是架空生育规则：男女皆可孕育，孩子记双方亲缘，继承双方的资质与特质。孩子18岁后进入人物册，可以继续任事、相识和成家。皇室沿原来的「家人和传承」培养、选储与交位，皇室同性交往的生育入口也不再被性别判断挡住，原有本人意愿与关系条件仍保留。

经营、婚育与家谱同属一个存档。没有固定世代终局；传位继续同一王朝，土地、钱粮、店面股份和旧家谱承接。

## 编辑配表

`editable-v34.xlsx` 是本轮的完整编辑表，约6.9万条文案包含当前构建实际引用的 JS / JSON 中的对白、选项、界面提示和模板片段，不能把这个数量当成独立NPC对白数。

- 「全部文案」：筛选来源文件，在「修改后文案」列填写新句子。留空沿用原句。编号、原文和隐藏定位字段不要改。
- 「原始万条对白」：原始11,520条条件对白，可直接修改NPC回答等字段；保留对白ID。
- 「新增NPC」「新增店铺」：新增人物背景、名字、店名、闲谈、小物和月分红。
- 「新增互动效果」：点击A后消耗的安排、内帑、好感、信任、所学和回复，改表后可实际生效。
- 「原有互动反应」「原有交互索引」：原有互动分支与真实实现位置。复杂旧事件涉及条件、延时回报、战斗和忠诚，不将源码自动猜成可执行Excel规则；需要改这些旧事件数值时按索引调整来源代码。
- 「婚育与传承规则」：结缘、赐婚、怀孕、出生、成年和继位的前提及结果。

改完将表命名为 `editable-v34.xlsx`，放在游戏目录，与 `rebuild-v34.py` 同级。双击 `rebuild-v34.cmd`（本机须有Python），按输出提示完成导入和重建，再打开 `index.html`。

也可运行：

```text
python 源代码/import_editable_v34.py editable-v34.xlsx
python 源代码/build_web_demo.py
```

文本修改不直接覆盖原始脚本，保存在独立替换记录里；源文件已变化时会中止导入并提示，避免错改。年龄与初始身份对新生成的人物生效，不重置旧档已经过的年龄。不要把Excel公式当作台词或代码填写。
