# 新手小引：先走几步，再理天下

界面设计沿用纸色、朱色与旧金，一次只出现一项当前任务。提示嵌在当前页面或对话框里，不另盖一层遮挡操作；用静态金色轮廓指出实际按钮，不使用持续闪动或依赖坐标的箭头。手机可收起、继续、跳过，无在线素材依赖。

## 入门六步

1. **看钱粮**：库银用于国事，内帑用于宫中；存粮养兵，叶氏借款要逐笔归还。每日六次日常、每旬两件国事分开计算。
2. **见人**：免费查看档案，点关心、问问近况。见面用一次日常安排，可聊三回。忙的人可以换一个，不强行清除差事。
3. **任用**：先认奉天殿布局，再从底部选人看人才册。亲自选一人实试，花库银20、1件国事。长处与家族背景都能看。
4. **探路**：在疆域图点失地，派斥候探敌情，花库银20、1件国事。不会自动出兵。
5. **换旬**：玩家先查看确认页，再实际经过余下日子，最后看山河记事。教程不偷偷快进，也不承诺私人约定停着不动。
6. **存进度**：认识自动存档、三格手动进度与完整下载入口；不强迫下载文件才能结束教程。

## 接着学用兵与地方

- 到军营看三类兵。补兵一百花银30、粮20、1件国事，也可用现有兵马。
- 在失地选将领与三类兵数。出征至少二百人，京畿至少留二百；确认才花银60、粮30、1件国事。
- 看敌军动向亲自下令，最多五令；可撤军，失败需整军再来，教程不自动获胜或补回战损。
- 收复后任知府，用1件国事。地方有经手人才交钱粮；后续可修田、核实际收入、查账，两旬后有实据再追款。

## 使用方式与边界

新局在开篇或荐选名册收起后，首次回到宫门时询问是否带着走。不会盖住尚未读完的开篇或替玩家确认候诏。关闭欢迎页视为暂缓，跳过后不反复弹出。

页首“新手小引”可随时翻操作小册、继续上次一步、重走入门或学用兵。每一步可以跳过，整段可收起或结束。重复教程只重走讲解，不重置世界，也不发奖励。

进行中的教程与完整存档一起保存。旧版进度不自动弹新教程，不重置日期、钱粮、人物或土地；V19/V20山河进度可手动开始，已经完成的实际任用与探路会被识别。没有山河玩法的更早存档只展示适用的存档、记事说明，不强塞新规则。

免费“带我去”只导航、打开档案或配置。招人、探路、补兵、出征、任官仍用原游戏按钮确认。国事用尽、钱不足、将领在地方任职、兵不足或战斗未结束时给出当前原因，不改状态替玩家过关。
