## 这次的开局

能拨到御前的国库银0、仓粮0，积欠俸饷96，内帑仅8。皇权掌控18，军心26、民心24、威望18；边患68、朝中内斗76。八地生计、治安、储粮与康健低，吏弊高。不是在原来富裕的开局上换一句“国势艰难”。

多数旧臣忠诚低、野心与影响力高。许知衡掌着旧荐举与签押，叶承钧握有钱粮门路；姜太傅仍愿护新帝，却没有钱兵替陛下兜底；陆景明能办事，也要看朝廷是否真能送来口粮。亲近、忠诚、能力与权势分别保留。

## 第一月怎样破局

1. 开场点击“临朝，先看空库册”，入朝耗1行动。殿内左上“危局 · 掌控18”可看救急、借据与朝臣底牌。
2. 可选三种无需先有国库钱粮的筹措，各耗1行动：封旧库点交（两日到银24粮36）、催解已核旧税（三日银18粮24）、接受叶氏垫付（一日银28粮36，立银债42粮债40，权臣影响增加、掌控下降）。每条来源有限，不会反复刷新发钱。
3. 点“翌日”等实际点交。随后入朝，从底部“奏”或右侧“御前呈报”批国用、赈贷与边事。预计效果仍要等回奏；没钱粮的方案依原规则不可批，不能把欠解当成已到手。
4. 满三日且掌控不足时，符合条件的强势主事可能扣住补签。一宗交涉可让一项实际在办事项迟两日，未解的签押还可能留置当月最多6银，转回待解。
5. 面对索权，可花1行动另核原册、两日交签；可暂许其荐员代签，让对方势力坐大；或花2行动当殿停其本案经手，承受更高内斗。不是看一句“虎视眈眈”就自动杀人或定谋反。

## 之后仍能继续经营

每月可花1行动催解已核旧项，最多12银，三日到账，从真实待解扣除。可花1行动定月末留最多6银续赈；这会少付本期俸饷，余欠和军民后果照记。叶氏借据每月按实还最多银6、粮4，先付国家原有岁计后才还；不够的继续欠着。

掌控低会使原执行评分承压；差事验收成功逐步加掌控，欠妥会减。国库、地方、臣子忠诚与权势共同决定你究竟能不能把旨意办下去。没有预设第几回合必败的结局。

人物闲谈、关心的陌生到熟悉过程、身世、选秀、邀约、争宠和记事继续沿用。本版重做的是国家开局与朝权经营，不把所有人改成一种口气或一律谋反。

## 旧存档与重新开局

已玩旧档继续原来的钱粮、人物和局势，不会被自动清空。要体验新设定，可到“记事”页底部，先“导出当前存档”，再点“查看重新开局确认”。只有确认重开后才清除当前浏览器这一份进度，进入风雨登基。新文件位置是否共享旧存档取决于浏览器。
