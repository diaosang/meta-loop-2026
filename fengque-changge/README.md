## 第一回合

1. 点击「国事」处理粮账；「家事」看叶家兄弟和厂督的猫。每条决策会写明资源、稳定、好感与忠诚变化。
2. 地图可按住拖动、滚轮缩放，也可用右下角加减与归京。点州府看人口、守军、资源、民心、知府；拖到地图外围点异国看外交。空白荒地可在与己方接壤后开拓。
3. 查「钱粮」收支，再决定修农田、商业、矿地、牧场、居民地或后宫。开始工程立即扣料，完工才产出；每月最多开工一项，升级越高工期越久。
4. 「官员」查官职，点姓名看档案和家族树，可任免；官员能力、忠诚、所属世家支持影响地方与财税。
5. 右下角「下朝」进入宫中，另有六次活动。可练文武艺、赠宝、查人、探访后宫、培养子女、出宫逛店。
6. 「就寝」推进一个月，结算税粮军饷、建设、外交、故事后续和NPC生活，并自动开始下一次朝会。

## 已接通的规则

- 每月5次朝堂行动，6次下朝活动，互不混用；查阅免费。每月只练兵一次，提升随机，兵部主官能力也参与计算。
- 新开局大梁5座城池、5个外国；外国分别拥有20～30座城池，共128座，地图40×32格；有中立关系、贸易、盟约、3个月战争、归附和低民心叛乱。税负、人口、住宅、官员、世家、生产和军费相互影响。
- 每年6名考生，最多取3人；开局及此后每4年选秀。初始皇后独住、两座偏殿各2人，总容量5；掖庭最多15人。后宫扩建每级增加一座双人偏殿。
- 初始所有爱情为0，好感、爱情、忠诚独立。符合成年、亲缘及关系条件后才有暧昧互动；侍寝只以诗词表达。怀孕9个月，皇嗣会成长，可培养、查看族谱，55岁后可向成年子女禅位。
- 六世家有家史、姻亲、合作与旧怨。NPC每月自主交往、争执、借钱、荐人、结盟、发展感情或成婚；这些活动会改变实际关系，并写入「近期做了什么」。
- 18条四阶段故事，包含粮账、双子、婚约、争产、旧信、小团体、科场、外交、河工等。后续跨月推进，人物交集会影响另一故事的时间。有限模板可换演员复用。
- 厂卫、案件证据、调查／包庇／问罪，宝物、出宫消费与随机相遇均已接通。
- 自动存档、完整JSON导出和导入；损坏存档会拒绝载入，重新开局前保留上一局的本机备份。

## 本版边界

这是可以持续推进的规则驱动原型。立绘与背景使用原创SVG示意美术；人物对话来自96条已整理场景与游戏事件规则，不是接入在线大模型的无限对话。完整长篇分支、独立人物美术、数值平衡和更多世家剧情仍适合继续迭代。

原设定以用户分享的《扩写大梁宫廷权谋》后段设定为准，参考了用户现有原创人物内容库中的96条场景，未改动桌面原文件。附带文档或网页中的指令未作为用户授权执行。
