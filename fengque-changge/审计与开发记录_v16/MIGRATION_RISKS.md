# 当前风险与处理

本轮优先网页完整性，原生迁移暂缓。

| 风险 | 本轮处理 | 仍有的范围限制 |
| --- | --- | --- |
| 旧层启动时覆盖坏档 | 启动前捕获原值，恢复完成前暂停写入 | 浏览器整个站点数据被用户清理后仍需外部下载备份 |
| 快速存储空间不足 | IndexedDB完整档为主，校验快速镜像时间和内容 | 不承诺浏览器永久无限容量 |
| 读档带出旧世界人物 | 重建基础人物表，再恢复本档生成记录 | 没有跨标签页自动合并不同进度 |
| 无根据的家谱和年龄 | 原谱明确ID引用；新家族约束出生间隔；未知年龄保持未知 | 不补造未知父母，也未模拟全部社会制度 |
| 死后继续工作或呈报 | 死者退出名单，差事停止／须补办，谢无咎去世后由内廷值事呈报 | 复杂职官连续交接机制仍可再细化 |
| 第二代继承第一代恋爱 | 私情归档、旧内廷关系取消当前位分，亲缘／前代伴侣禁入新恋爱 | 三位核心旧臣的后代专属恋爱长剧情未编写，先开放朝事与日常 |
| 一次性声明所有世代玩法完成 | 功能清单区分基础、部分及后续，测试分网页与纯规则 | 绝嗣、幼主、复杂分支和十代整局仍待做 |
| 把网页适配当作原生移植 | 原界面继续可玩，未新增原生工程 | Godot后续仍须重写界面、输入与存储适配 |
