# 凤阙长歌 V15 · 山河与人间

在原整合包的大梁设定、100名人物、八地地图、许案、原大殿与家族继承基础上，新增按日经营。首段可连续运行30日，此后继续按月、季节与年份推进，没有固定回合终局。

## 操作先说人话

按钮使用「先找钱和粮」「给百姓送粮」「修水渠」「给官兵发钱」「让谁去做」。首页先看吃饭、安全和下一步，详细数值、税令及阶段目标按需展开；人物说话保留古代语气。

## 开始与继续

新局点击序章的「临朝」即进入经营。已有存档从导航「经营」接手，现有国库、仓粮、好感、家族与旧案保留；只把行动改为每日六点精力。每日「今日就寝」进入翌日，30日后自然进入下月。若急着收月，先显示确认，再逐日处理余下时间和所有期限。

一天分卯、辰、午、未、申、戌、亥七段，由消耗的六点精力推进。会面仍一次精力、三次交谈；只查看档案、回奏、地图与规则不耗时。并不要求每日逐项打卡，缺席普通闲暇没有惩罚，已有重大奏事期限照常存在。

## 起手可走的路

国库0、仓粮0、欠饷96、内库8。先从「筹措钱粮」清点旧库，候两日回册。到粮后可以先赈济，或保留军粮做江南修渠、京畿复耕，另用国库补一笔欠饷。姜叶借力、商路借粮仍沿用原有危局路线，不会因新增经营而免费填满国库。

| 系统 | 实际规则 |
| --- | --- |
| 国库与仓粮 | 每日拨军粮1；每五日按地方生计、腐败与税令征税，应付俸饷12，未付累入旧欠 |
| 地方生计 | 缺粮积累流民，粮价上涨、治安和民心降低；欠饷高会进一步拖累治安 |
| 水利与复耕 | 水患高且遇雨损粮；基础设施、水利、治安均足够，才产生周期性粮入 |
| 税令 | 薄赋保民生；加征增眼前税入，同时损民心和商情。每月只改一次，两个入口共享限制 |
| 施政 | 赈济、修渠、驿路、核账、复耕；实扣钱粮、指定真实在任官、2至6日验收 |
| 承办能力 | 能力不足45者延一日，完成效果只达六成；同一人不能同时接两个经营差事 |
| 地方景象 | 荒田、常市、夜市、堤岸分别判定；高繁荣无法掩盖空粮、吏弊或不安的治安 |

重点面板先看京畿、江南、北境，其余五地也参与运转。此版景象是程序化的简洁图形与文字状态，尚未新增完整场景美术。

## 人物会做自己的事

人物按身份、当日差事、天气与存档种子留下七段行程，保存在记事中。许知衡会核账与追查旧卷，姜禹瀛会核荐册，谢无咎会出去核实来话；领办工程时会忙至交卷，可以婉拒私下召见，不扣玩家精力。政治指令仍有正常入口。

人物压力与健康随差事和饥荒变化。许、姜、叶、谢之间每隔两日发生一次有内容的工作往来：对册、荐举、商路、核证，各有立场，并留双方记忆。它们由规则与目标驱动，不使用联网大模型，也不代表真实意识。

关心与闲谈接到实际差事与欠饷背景，仍只显示 NPC 回复；已完成的交谈才增加相处记忆，查看不能刷熟悉。陌生、熟悉、相知继续沿用原来的多日对话与信任门槛，政治忠诚不等于私下好感。许知衡不入后宫，姜禹瀛不因关心而放弃家族立场，谢无咎的身份仍须本人在信任后说明。

## 节令和生活

上巳、端午、中秋、冬至、除夕有日期入口。聚饭、看花、垂钓、闲书、便服逛市留下生活记忆，休闲每日至多一次；这些活动不凭空增加政治能力、魅力或国库。错过一次节令不会中断游戏。

## 选秀三项修正

1. 首届殿选免安置费，即使内库0也可正常留人。取消本届也视为用过首届机会，后届恢复每人12。不得用旧存档反复套取首届优惠。
2. 当场试艺后，许知衡、姜禹瀛、叶承钧依据当届试簿和各自立场回应。已试人选可以比较；不同专长分别列项。查看与重开面板不重掷失手，也不重复奖励。
3. 谢无咎区分亲见、簿册事实、待核线索和无实据。已有争执影响安置建议，怯场不等于坏人；真实生成的荐举暗线可交核两日。回册只确认荐书联系，不能直接定罪；退出选秀后核查仍继续，结果入记事。

原有成年、家世与才艺资格、三问、本人同意、至多留两人、住房和后续相处规则保留。

## 实录、长期目标与技术范围

五个阶段目标为稳住御座、重建生计、整顿吏治、安定边防、百业渐兴。达成只是一段历史，之后照常变化，不锁死后续路线。

界面入口叫「这一年的记事」。日常行程保留最近七天，重要人物记忆与年度记录另存；旧存档历史先归入年度记录，不会因为记事首页只保留800条而消失。只有月份的旧记事标为「日子未记」，不补造具体日期。

《大梁实录》按年份收纳实际经营、任官、旧案、生活与人物事件，可导出 JSON。不会自动编造死伤、婚约、查抄人数或结局。已有完整游戏存档另从记事导出。

此版完成首段经营闭环及原有世代玩法的接续，尚未实现数万独立人口代理、完整一生剧情或所有地区独立战场。经营规则已拆出为 JSON + 纯规则内核；Godot 提供数据接口骨架和移植说明，旧恋爱、选秀等系统仍需后续迁移。详见 `Godot移植/移植说明.md`。
