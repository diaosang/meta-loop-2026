# 凤阙长歌 · V9.1 自然对话改造

## 本轮定位

V9.1 先解决“玩家问的是具体话题，NPC 却给出泛化台词”的错位，不改朝堂、选秀、数值、行动消耗、事件触发和存档结构。

## 已定位的旧逻辑问题

人物互动有两层文案覆盖：底层按“类别 + 具体话题”查找对白；后续修订层又用 \`revisionRow(person, category)\` 覆盖回复，只看“闲谈 / 关心 / 活动 / 调情”等大类，不再看玩家点的是“近况 / 故乡 / 下棋 / 散步 / 想念”中的哪一个。结果是玩家问 A，NPC 可能答一段不对题的 B。

## V9.1 改动

1. **话题优先**：在同一轮互动中，按 NPC、互动类别、具体话题读取对应对白。
2. **一轮一个目的**：不再追加“心境补句”“暧昧补句”或无关的记忆钩子。长回复如包含三段以上独立句子，优先保留第一个完整落点。
3. **场景可观察**：会面场景只写具体动作，例如放下文书、收起家书、取出棋盘；不追加心态和神态旁白。
4. **同轮不换词**：同一轮中，展示对白与写入记事使用同一条缓存结果，避免玩家看到一条、记事却记录另一条。
5. **不碰玩法**：数值变化仍交给原有 \`applyInteraction\`；记忆仍由原有系统写入；只替换返回给交互层的对白记录。

## 本轮覆盖范围

- 人物拜访时的“近况”开场。
- 八类互动中有具体话题配表的选项。
- 具体话题缺少配表时，自动回退旧版文案，不阻断互动。

随机事件、朝堂奏折、选秀与其他非人物互动对白尚未在本轮逐条重写；后续应按事件触发条件与人物关系分别校准，不能用统一过滤器批量删句。

## 验收标准

- 玩家问“近来在忙什么”，回复先交代当下事务。
- 玩家选“散步”，回复围绕散步本身，不突然转到暧昧承诺或另一件旧事。
- 玩家表达想念，NPC 根据人物性格和关系回应，不统一说“我也想你”。
- 场景只保留能观察到的动作；情绪、关系立场交给对白与后续行为表达。
- 连续重复同一话题时可以换一条同题回答，但不能改成答非所问。
- 原有行动、数值、朝堂和事件逻辑不发生变化。
