# V18 · 心意与相伴

以2026年11月6日新提供的《NPC互动系统·最终修订版》为本轮设计依据，在V17整合包继续改动。网页版默认入口为`index.html`，独立入口`试玩_v18.html`；Godot移植暂缓。

## 十个入口怎样用

点击立绘先免费看人物，再选一项。默认两列十项，不把数值表和全部分支同时铺开。

| 关心 | 身体压力、实际亲属与家计；有具体不快时才说开，不靠一句话治病 |
| 赏赐 | 按喜好赐物与按实绩论赏；宫里用钱、朝廷银分别记账 |
| 邀约 | 饮茶、游园、下棋与明日之约；核对忙闲，能婉拒、延期、主动补约 |
| 暧昧 | 夸赞、逗趣、挂念、试着牵手、表明心意、约定信物；独立主项 |
| 侍寝 | 查看条件、先听本人回话、确认今夜或明夜的亥初／子初、取消、夜景和次晨记忆；独立主项 |

资料、经历、内廷条件和确认前的回话免费。一场会面用1次安排，可说3回话。侍寝定约另用1次安排，不占会面交谈，实际赴约不再扣；提前遣人取消不算失约，但传召已经花掉的安排不返还。

## 情意单独记，关系不能由封位代替

关系折叠展示七项：熟悉、信任、亲近、情意、敬重、忠诚、戒备。`relations.love`继续承接旧存档数值，可见含义改为情意；旧数值不会自动补写“双方已互通心意”。新相处在本代人物记录`emotion`中保存接受过的回应、实际日期与明确同意。

关系经历「礼数周全→熟悉→亲近→暧昧→心意相通」。熟悉按不同日的实际交谈；暧昧要求至少两日接住彼此示好；明确心意还要更多日期、信任与亲近，以及本人正面回应。许知衡比普通路线多留一日，不会只凭几次同日点击便敞开心意。

初识的夸赞可能只得到拘谨回话；戒备、受伤或生气时可以拒绝。拒绝不涨情意、不扣政治忠诚，也不暗改成已经同意。每天至多一次推进暧昧，信物本代一次，不能反复换按钮刷数值。去掉旧版“入宫即自动情意50以上”的加成，原存档已有数值照留。

三位主角单写回复；其余人物按十二种性情分配不同的夸赞、逗趣、挂念、牵手、表白和主动请见。实际说过的回复参与选句去重，有限文案池用尽后仍可能重现，不宣称无限生成。

## 三人的边界

| 人物 | 感情与身份 |
| --- | --- |
| 许知衡 | 能克制地动心并亲口回应；仍不入后宫，保留首辅职分与政治理想。本轮没有编造一段让他改口的完整剧情，因此侍寝持续关闭。 |
| 姜禹瀛 | 温雅而有试探，回应心意也说明姜氏与朝职仍有独立立场。未完成真实的身份变动与入宫同意，侍寝持续关闭。 |
| 谢无咎 | 秘密身份须沿原剧情亲口说明；成年、真实入宫封位、相互心意与当日状态齐备，才可定约。高忠诚不能跳过上述条件。 |

不凭设计文档举例新增东厂、西厂、锦衣卫，也不凭一条对话判案或赐死。原有任用、荐举、册封与查证仍按真实操作处理；更完整的抄家、赐死、联姻和惩戒流程未在本轮新增。

## 侍寝是有后续的约定

要求双方成年在世，NPC为男性、已有内廷封位，不在外朝任职，并符合原亲缘、婚姻、前代伴侣与角色边界。至少互通心意，且信任、亲近、情意、戒备都适宜。病中、疲倦、心有隔阂、办差未归、上朝或出巡，均会据实回话。

确认时再查一遍条件；同一夜只留一人，同一个人有未赴的约时不能另占一夜。今夜约定在次晨结算，明夜约定再多等一天。赴约前仍重查身体、身份与意愿，临时不能相陪便记未成，不补写已发生的夜景。跨过多日的旧约也不倒填相会。

用夜色、停顿、对话和留白表现，不描写露骨过程。首次、再度相陪及确实久未见面的重逢分别记在经历里，次晨能查看完整场景。约定、取消、未成和实际相陪都有独立编号与来源；死亡或继位后不复活、不继承旧君主的私约。

侍寝不自动有孕。子嗣仍须在「家人和传承」中另行商量，按月独立判定：父母年岁、身体、生育状态和概率参与，不再三个月必然有孕；确认后仍需约九个月照看。默认健康、育龄范围与概率用于游戏模拟，不是现实医学模型。

## NPC主动来往

沿用V17有依据的补约、家事求助与政见请陈，另增加主动示好、亲手赠物、因实际内廷安排吃醋、争执后求和、正式后宫人物主动请侍。书签与棋解等小物来自本人，不是玩家花钱买好感。

新主动事件要求真实接触与已回应的心意，受人物性情、戒备、忙闲和已发生的事影响。有冷却与概率，回绝或放置会减少以后接近的机会，不每天齐刷刷来信。吃醋指向实际有封位人物的相陪记录，求和须有真实受伤或生气的相处来源；请求侍寝仍须进入回话与确认，不能由NPC发来一封信就自动执行。

私人来往放在记事的小笺入口；御前要事仍走谢无咎呈报，日常动向仍在记事。
